# История обновлений BTC Monitor Bot

## Версия 1.7.0 (2026-04-07)
**Чат с администратором и система рассылки внутри Mini App**
*Название коммита:* `mini-app-chat-and-broadcast`
- **Чат**: Добавлена вкладка "Связь" в Mini App. Пользователи теперь могут общаться с администратором в реальном времени, а администратор может отвечать конкретным пользователям прямо из админ-панели (вкладка "Админ" -> "💬 Чат"). История сообщений сохраняется в `state.json`.
- **Массовая рассылка**: В админ-панели Mini App добавлен раздел для массовой рассылки. Администратор может выбрать всех или некоторых пользователей (через чекбоксы) и отправить им сообщения.
- **Взаимодействие с Telegram**: Отправленные в Mini App сообщения дублируются уведомлениями в Telegram (как для юзеров, так и для админа).

## Версия 1.6.0 (2026-04-07)
**Обновление дизайна Mini App и фиксы багов**
*Название коммита:* `mini-app-redesign-and-fixes`
- **Дизайн**: Полностью переработан UI веб-приложения (`index.html`). Использованы нативные CSS переменные Telegram для идеальной интеграции с любой темой (светлой/тёмной). Улучшена типографика, добавлены тени, скругления и красивые Toast-уведомления.
- **Очистка UI**: Удалены устаревшие кнопки "Открыть Mini App" (поскольку он открывается через кнопку вложений) и тестовая кнопка "Test Notify" (вместе с соответствующими функциями в коде бота).
- **Исправление багов**: Улучшена стабильность цикла `monitor_loop`. Теперь ошибки API при запросе деталей транзакции не приводят к пропускам обработки, а корректно логируются и повторяются в следующем цикле.

## Версия 1.5.0 (2026-03-29)
**Интеграция Telegram Mini App**
*Название коммита:* `mini-app-integration`
- **Веб-приложение**: Добавлено полноценное встроенное веб-приложение (`index.html`) для удобного управления адресами через интерфейс (SPA).
- **Встроенный API**: В `monitor_bot.py` интегрирован асинхронный HTTP-сервер на базе `aiohttp` для работы Mini App.
- **Безопасность**: Запросы от Mini App защищены и верифицируются через алгоритм Telegram (`initData` HMAC-SHA-256).
- **Админ-панель в Web**: Добавлена вкладка администратора внутри Mini App для быстрого управления пользователями и их адресами.
- **Обновление зависимостей**: Библиотека `aiohttp` добавлена в список зависимостей в `requirements.txt`.

## Версия 1.4.0 (2026-03-28)
**Миграция API: Переход на BlockCypher**
*Название коммита:* `api-migration`
- **Новый API**: Опрос сети Bitcoin переведён с `blockstream.info` на `blockcypher.com` для обхода лимитов и ошибок 429.
- **Токенизация**: Добавлена поддержка `API_TOKEN` для сервиса BlockCypher в `config.json`.
- **Оптимизация подтверждений**: Обновлена логика выявления 0 и 1+ подтверждений в мемпуле по правилам нового API.

## Версия 1.3.0 (2026-03-28)
**Улучшение админ-панели и система рассылки**
*Название коммита:* `admin-broadcast`
- **Добавление адресов**: Администратор теперь может напрямую добавлять названия групп и BTC-адреса в профиль любого пользователя.
- **Система рассылки**: Добавлена функция выборочной рассылки. Администратор может отметить конкретных пользователей в списке и отправить им текстовое сообщение.
- **Обратная связь**: Пользователи, получившие сообщение от администратора, видят кнопку «Ответить». При её нажатии они могут отправить текстовое сообщение, которое напрямую пересылается администратору (с указанием профиля отправителя).

## Версия 1.2.0 (2026-03-28)
**Админ-панель и управление пользователями**
*Название коммита:* `admin`
- **Профиль пользователя**: Бот теперь сохраняет `username` и `first_name` пользователей для удобной идентификации.
- **Панель администратора**: Добавлена эксклюзивная админ-панель (доступна только для ID 5381999598).
- **Управление пользователями**: Администратор может просматривать список всех пользователей бота.
- **Управление адресами**: Администратор может просматривать адреса каждого пользователя и удалять их при необходимости.
- **Отключение уведомлений**: Добавлена возможность точечно отключать уведомления для конкретного адреса пользователя (адрес остаётся в базе, но мониторинг по нему не отправляет сообщения этому пользователю).

## Версия 1.1.0 (2026-03-23)
**Многопользовательский режим и оптимизация**
- **Общедоступность**: Бот теперь поддерживает неограниченное количество пользователей. У каждого свой личный список адресов и групп.
- **Миграция данных**: Добавлена автоматическая миграция `state.json` из старого формата в новый при первом запуске.
- **Оптимизация API**: Переписан `monitor_loop`. Теперь опрос идет по списку уникальных адресов (не дублируется, если несколько пользователей добавили один и тот же адрес).
- **Удаление ограничений**: Удалены проверки `ADMIN_CHAT_ID` в обработчиках команд.
- **Документация**: Создан файл `docs.md` с описанием работы бота.

## Версия 1.0.0 (Начальная)
**Базовый функционал мониторинга**
- Отслеживание входящих транзакций (unconfirmed).
- Отслеживание 1 подтверждения.
- Управление адресами (добавление, удаление, редактирование).
- Поддержка только одного администратора.
