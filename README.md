# BTC Monitor Bot

Telegram-бот для мониторинга входящих транзакций в сети Bitcoin. Бот автоматически отслеживает добавленные адреса и отправляет уведомления о новых транзакциях (unconfirmed) и получении первого подтверждения.

## Особенности
- **Многопользовательность**: Бот может использоваться неограниченным числом пользователей. Каждый имеет свой независимый список адресов.
- **Группировка адресов**: Адреса можно группировать под произвольными названиями для удобства.
- **Оптимизированный опрос**: Мониторинг (API BlockCypher) группирует одинаковые адреса от разных пользователей для минимизации запросов.
- **Конвертация в USD**: Бот показывает актуальную стоимость полученных BTC в долларах США.
- **Telegram Mini App**: Полноценное веб-приложение внутри Telegram для удобного управления своими адресами и админ-панелью.
- **Встроенный чат**: Пользователи могут общаться с администратором напрямую через вкладку "Связь" внутри Mini App (с сохранением истории).
- **Массовая рассылка**: Администратор может осуществлять рассылку уведомлений выбранным пользователям непосредственно из интерфейса Mini App.
- **Панель администратора**: Специальный интерфейс (доступен как по кнопкам, так и в Mini App) для управления пользователями и их адресами (доступен только для владельца).

## Установка и запуск (Ubuntu)

Бот и встроенное Mini App можно развернуть на сервере Ubuntu.

1. Клонируйте репозиторий.
2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
   *Основные библиотеки: `python-telegram-bot`, `httpx`, `aiohttp`.*
3. Создайте файл `config.json` в корневой директории бота:
   ```json
   {
     "BOT_TOKEN": "ВАШ_ТЕЛЕГРАМ_ТОКЕН",
     "POLL_INTERVAL": 20,
     "API_BASE": "https://api.blockcypher.com/v1/btc/main",
     "API_TOKEN": "ВАШ_BLOCKCYPHER_TOKEN",
     "ADMIN_CHAT_ID": "5381999598",
     "WEB_PORT": 8080,
     "WEBAPP_URL": "https://ваший-домен.com/"
   }
   ```
   > **Важно**: Для работы Mini App у вас должен быть настроен HTTPS-домен, который ведет на порт `8080` (по умолчанию). Вы можете использовать `nginx` в качестве reverse proxy или утилиты вроде `ngrok` или `cloudflared`.

4. **Настройка Nginx для Mini App (Опционально)**:
   Если у вас есть домен, настройте проксирование:
   ```nginx
   server {
       listen 443 ssl;
       server_name ваший-домен.com;
       
       ssl_certificate /etc/letsencrypt/live/ваший-домен.com/fullchain.pem;
       ssl_certificate_key /etc/letsencrypt/live/ваший-домен.com/privkey.pem;

       location / {
           proxy_pass http://127.0.0.1:8080;
           proxy_set_header Host $host;
           proxy_set_header X-Real-IP $remote_addr;
       }
   }
   ```
   *После этого добавьте ваш URL (например, `https://ваший-домен.com/`) в настройки бота в `config.json` как `WEBAPP_URL`.*

5. Запустите бота:
   ```bash
   python3 monitor_bot.py
   ```

## Использование

- `/start` — запуск бота и открытие главного меню.
- **Главное меню**:
  - `📱 Открыть Mini App` — интерфейс для удобного управления адресами (если настроен `WEBAPP_URL`).
  - `📂 Список адресов` — просмотр ваших групп и адресов (по кнопкам).
  - `➕ Добавить адрес` — добавление нового адреса (по кнопкам).
  - `🗑 Удалить название` — удаление группы.
  - `🔁 Test notify` — отправка тестового уведомления.

## Админ-панель

Доступна пользователю с ID из `ADMIN_CHAT_ID`.
В **Mini App** администратору автоматически доступна вкладка **"Админ"**. В ней можно:
- Управлять адресами всех пользователей.
- Отключать и включать уведомления для конкретных адресов.
- Добавлять адреса пользователям.

Функция **Рассылки сообщений** доступна через стандартную кнопочную панель администратора в чате бота.

## Структура данных

Бот хранит все данные в файле `state.json`. В нём содержатся:
- Данные пользователей (ID, username, first_name, группы, адреса, настройки уведомлений `notify_disabled`).
- Неподтверждённые транзакции (для отслеживания 1-го подтверждения).
- Состояние уже уведомлённых транзакций.

## Разработчику

Для внесения изменений в логику:
- Бот использует встроенный веб-сервер на базе `aiohttp` для обслуживания Mini App (отдаёт `index.html` и работает как API).
- Взаимодействие с Telegram API реализовано на `python-telegram-bot` с использованием `CallbackQueryHandler` и `MessageHandler`.
- Цикл мониторинга (`monitor_loop`) работает асинхронно в фоне.
- Обращайте внимание на функцию `load_state` и `save_state` при модификации структуры данных.
