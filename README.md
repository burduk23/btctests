# BTC Monitor Bot

Telegram-бот для мониторинга входящих транзакций в сети Bitcoin. Бот автоматически отслеживает добавленные адреса и отправляет уведомления о новых транзакциях (unconfirmed) и получении первого подтверждения.

## Особенности
- **Многопользовательность**: Бот может использоваться неограниченным числом пользователей. Каждый имеет свой независимый список адресов.
- **Группировка адресов**: Адреса можно группировать под произвольными названиями для удобства.
- **Оптимизированный опрос**: Мониторинг (API BlockCypher) группирует одинаковые адреса от разных пользователей для минимизации запросов.
- **Конвертация в USD**: Бот показывает актуальную стоимость полученных BTC в долларах США.
- **Telegram Mini App**: Полноценное веб-приложение внутри Telegram для удобного управления своими адресами и админ-панелью. Поддерживает переключение тем (Авто, Тёмная, Киберпанк).
- **Встроенный чат**: Пользователи могут общаться с администратором напрямую через вкладку "Чат" внутри Mini App. Поддерживается отправка изображений, просмотр истории и уведомления в Telegram.
- **Массовая рассылка**: Администратор может осуществлять рассылку уведомлений выбранным пользователям непосредственно из интерфейса Mini App (включая изображения).
- **Панель администратора**: Специальный интерфейс (доступен как по кнопкам, так и в Mini App) для управления пользователями и их адресами (доступен только для владельца).
- **Курс обмена**: Быстрое получение актуального курса BTC к RUB через встроенную функцию "Обмен" (парсинг onemoment.cc).

## Установка и запуск (Ubuntu)

Бот и встроенное Mini App можно развернуть на сервере Ubuntu.

1. Клонируйте репозиторий.
2. Создайте виртуальное окружение и активируйте его (рекомендуется):
   ```bash
   python3 -m venv venv
   source venv/bin/activate  # Для Windows: venv\Scripts\activate
   ```
3. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   playwright install chromium
   playwright install-deps
   ```
   *Основные библиотеки: `python-telegram-bot`, `httpx`, `aiohttp`, `playwright`.*
4. Создайте файл `config.json` в корневой директории бота:
   ```json
   {
     "BOT_TOKEN": "ВАШ_ТЕЛЕГРАМ_ТОКЕН",
     "POLL_INTERVAL": 20,
     "API_BASE": "https://api.blockcypher.com/v1/btc/main",
     "API_TOKEN": "ВАШ_BLOCKCYPHER_TOKEN",
     "ADMIN_CHAT_ID": "5381999598",
     "WEB_PORT": 8080,
     "WEBAPP_URL": "https://ваш-домен.com/"
   }
   ```
   > **Важно**: Для работы Mini App нужен HTTPS-адрес. В этом проекте можно использовать **Cloudflare Tunnel** — это удобный способ опубликовать локальный веб-сервер бота без открытия 443 порта и без Nginx-конфигурации.

5. **Настройка Cloudflare Tunnel для Mini App (рекомендуется)**:
   Этот вариант подходит, если 443 порт уже занят VPN или вы не хотите настраивать Nginx и сертификаты вручную.

   **Шаг 1.** Добавьте домен в Cloudflare и поменяйте NS-записи у регистратора на те, которые выдаст Cloudflare.

   **Шаг 2.** На сервере установите `cloudflared`:
   ```bash
   wget https://github.com/cloudflare/cloudflared/releases/latest/download/cloudflared-linux-amd64
   chmod +x cloudflared-linux-amd64
   sudo mv cloudflared-linux-amd64 /usr/local/bin/cloudflared
   ```

   **Шаг 3.** Авторизуйтесь в Cloudflare:
   ```bash
   cloudflared tunnel login
   ```

   **Шаг 4.** Создайте туннель:
   ```bash
   cloudflared tunnel create btcbot
   ```

   **Шаг 5.** Привяжите домен к туннелю:
   ```bash
   cloudflared tunnel route dns btcbot ваш-домен.com
   ```

   **Шаг 6.** Создайте конфиг:
   ```bash
   sudo mkdir -p /etc/cloudflared
   sudo nano /etc/cloudflared/config.yml
   ```
   Пример содержимого:
   ```yaml
   tunnel: btcbot
   credentials-file: /root/.cloudflared/ВАШ_TUNNEL_ID.json

   ingress:
     - hostname: ваш-домен.com
       service: http://127.0.0.1:8080
     - service: http_status:404
   ```

   **Шаг 7.** Запустите туннель:
   ```bash
   cloudflared tunnel run btcbot
   ```

   **Шаг 8.** Для автозапуска установите сервис:
   ```bash
   sudo cloudflared service install
   sudo systemctl enable --now cloudflared
   ```

   После этого добавьте ваш URL, например `https://ваш-домен.com/`, в `WEBAPP_URL`.

6. Запустите бота:
   ```bash
   python3 main.py
   ```

## Использование

- `/start` — запуск бота и открытие главного меню.
- **Главное меню**:
  - `💱 Обмен` — проверка актуального курса и расчёт суммы в RUB.
  - `📱 Открыть Mini App` — интерфейс для удобного управления адресами (если настроен `WEBAPP_URL`).
  - `📂 Список адресов` — просмотр ваших групп и адресов (по кнопкам).
  - `➕ Добавить адрес` — добавление нового адреса (по кнопкам).
  - `🗑 Удалить название` — удаление группы.
  - `🔁 Test notify` — отправка тестового уведомления.

## Админ-панель

В **Mini App** администраторам автоматически доступна вкладка **"Админ"**. В ней можно:
- Управлять адресами всех пользователей.
- Отключать и включать уведомления для конкретных адресов.
- Добавлять адреса пользователям.
- Осуществлять массовую рассылку сообщений и общаться с пользователями.

**Управление администраторами**: Главный администратор (указанный в `ADMIN_CHAT_ID` в `config.json`) может назначать дополнительных администраторов. Это можно сделать через кнопку "Управление администраторами" в админ-панели бота или в соответствующем разделе вкладки "Админ" в Mini App. Дополнительные администраторы получают доступ ко всем функциям управления пользователями и рассылкам, но не могут добавлять или удалять других администраторов.

Функция **Рассылки сообщений** доступна как через стандартную кнопочную панель администратора в чате бота, так и через Mini App.

## Структура данных

Бот хранит все данные в файле `state.json`. В нём содержатся:
- Данные пользователей (ID, username, first_name, группы, адреса, настройки уведомлений `notify_disabled`).
- Неподтверждённые транзакции (для отслеживания 1-го подтверждения).
- Состояние уже уведомлённых транзакций.

## Разработчику

Для внесения изменений в логику:
- Бот использует встроенный веб-сервер на базе `aiohttp` для обслуживания Mini App (отдаёт `index.html` и работает как API).
- Взаимодействие с Telegram API реализовано на `python-telegram-bot` с использованием `CallbackQueryHandler` и `MessageHandler`.
- Цикл мониторинга (`monitor_loop`) работает асинхронно в фоне.
- Обращайте внимание на функцию `load_state` и `save_state` при модификации структуры данных.
